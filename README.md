# SWYNEX – Data Cleaning & Preparation

## Project overview
This project cleans the provided retail store sales dataset using Python and pandas. The script reads `retail_store_sales.csv` and creates `SWYNEX-cleaned-retail-sales.csv`.

## Files
- `retail_store_sales.csv` – original dataset
- `cleaning_script.py` – reproducible Python cleaning script
- `SWYNEX-cleaned-retail-sales.csv` – cleaned output generated by the script
- `CLEANING-SUMMARY.md` – cleaning results and validation notes
- `README.md` – project documentation

## Cleaning steps
1. Trim whitespace and normalize blank text cells.
2. Remove exact duplicate rows.
3. Convert price, quantity, and total-spent fields to numeric values.
4. Fill missing item and discount labels with `Unknown`.
5. Calculate missing unit prices only when total spent and a positive quantity are available.
6. Parse and standardize transaction dates to `YYYY-MM-DD`.
7. Check duplicate transaction IDs and compare `Price Per Unit × Quantity` with `Total Spent` where all values are available.

## Run the project
Install the dependencies:
```bash
pip install pandas
```
Keep all project files in the same folder, then run:
```bash
python cleaning_script.py
```
The script writes `SWYNEX-cleaned-retail-sales.csv` in the same folder and prints a cleaning report.

## Notes
Missing `Quantity` and `Total Spent` values are retained rather than guessed or deleted. The script only calculates a missing unit price when the required source values are present and quantity is greater than zero.
